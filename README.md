# Naxed Server 8.6 → Protocol 15+ (Revamp)

## Descripción
Revamp completo del clásico Naxed Server 8.6, actualizado al protocolo 15+ y en evolución continua.  
El proyecto integra sistemas modernos, áreas de mapa rediseñadas, quests mejoradas y una fusión de ecosistemas para ofrecer una experiencia renovada sin perder la esencia original.

## Características principales
- **Protocolo 15+** – Compatibilidad con clientes actuales.
- **Actualización diaria** – Sistemas, mapa y quests en mejora constante.
- **Data Pack basado en los nuevos distros de Open Tibia Server** – Código base estable, optimizado y alineado con las últimas versiones de OTServ.
- **Ecosistemas integrados** – Unificación de mecánicas y contenido de distintas fuentes.

## Basado en
Este Data Pack utiliza las distribuciones más recientes de **Open Tibia Server**, garantizando rendimiento, seguridad y compatibilidad con el protocolo 15+.

## Inicio rápido
1. Clona el repositorio.
2. Compila el servidor con las nuevas distros de OTServ.
3. Ejecuta el schema SQL en tu base de datos.
4. Inicia el servidor y conecta con un cliente 15+.
